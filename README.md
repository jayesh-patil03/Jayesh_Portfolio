# Jayesh Patil — Developer Portfolio

A responsive, static portfolio focused on Java backend development, Spring Boot, APIs, databases, and cloud deployment. Built with HTML, CSS, and vanilla JavaScript.

## Run locally

1. Open this folder in VS Code.
2. Use the Live Server extension, or run a local server from this folder:

   ```bash
   python -m http.server 5500
   ```

3. Visit `http://localhost:5500`.

You can also open `index.html` directly, though a local server is recommended.

## Deploy

This is a static site and can be hosted on GitHub Pages, Netlify, or Vercel. For GitHub Pages, push the files to a repository and select the branch and root folder under **Settings → Pages**.
